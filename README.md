# Asad Ullah Khan — Portfolio

Personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion to showcase my software projects, web applications, and AI workflows.

---

## Skills & Technologies

- **Languages & Backend**: Java, C++, Python, Node.js
- **Frontend & Web**: React, Next.js, Web Development, UI/UX Design
- **AI & Automation**: AI Workflows, ComfyUI, LLMs, Prompt Engineering

---

## Quick Start

```bash
# Clone the repository
git clone https://github.com/ssxAsad/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
